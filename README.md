# Java Practice

A collection of Java programs and coding exercises focused on programming fundamentals, problem-solving, and continuous learning.

## Repository Structure

### Practice
Java programming concepts and exercises, including:
- Variables and Data Types
- Methods and Constructors
- Arrays
- Conditional Statements
- Loops and Nested Loops
- Object-Oriented Programming
- Strings
- Recursion
- Patterns

### JavaTPoint
Independently solved programming problems, organized into:
- Basic Programs
- Number Programs
- String Programs
- Pattern Programs
- Array Programs

## Learning Approach

For each problem, I focus on:
- Developing logic independently
- Exploring different approaches
- Practising different loops and techniques
- Performing manual dry runs
- Understanding code optimization
- Analysing time and space complexity
